# Instrucciones del proyecto LINGORA

Mantener BITACORA.md según la skill `bitacora-proyecto`, conservando el historial y registrando cada solicitud y su resultado.

Cuando el usuario solicite hacer push, subir cambios o actualizar este proyecto en GitHub, leer y aplicar [lingora-push-dual](docs/skills/lingora-push-dual/SKILL.md). Publicar el mismo commit en `main` de `Lingora-IA/LINGORA-IA-V2` y `Boundedman/LINGORA_IA`, salvo que el usuario limite expresamente el destino.
